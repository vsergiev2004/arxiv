## Semantic
### Инструменты
Часть отвечающая за семанитический+BM25 поиск релевантных статей по запросу.  
В качестве управляющего процессом ИИ используется gpt-oss-120b, через API groq'а, такой выбор был сделан в силу бесплатности ресурса.  
Ембеддинги делаются при помощи specter2, она обучена на тех же данных, что и используются мной(т.е. title, abstract). У specter2 есть два адаптера(они соответствуют навыкам агента)  
Результаты семантического поиска и BM25 сравниваются и выводятся в соответствии с положениями в списках вывода.  

Есть два навыка:
### query-to-article
По запросу **query** ищет **top-k** семантически ближайших статей по запросу
### article-to-article
По номеру статьи ищет похожие на неё
### Качество
Оценено неформально(моей работой над курсовой, на ней результаты весьма хорошие, мои запросы получают релевантные статьи в top-k). Для формальной оценки советуется ознакомиться с результатами specter2, так как модель не была мной дообучена и качество не должно отличаться от официальных чисел

## RAG
Пока сделан в формате **top-k** лучших чанков. Сами чанки разбиты по контексту, но методы такого разбиения эвристические.  
Для эмбеддингов чанков используется bge-small-en-v1.5, так как она обучена на научной литературе.
