# science-searcher
Агент для работы с научными статьями

## Содержание
- [Semantic](#semantic)
- [RAG](#rag)
- [Планы](#планы)

## Архитектура агентов
Оба модуля (Semantic и RAG) используют единый паттерн:
- Управляющий ИИ — **gpt-oss-120b** через API Groq'а
- Управление через **function calling** — агент сам решает, какой инструмент вызвать
- Multi-turn цикл: запрос → LLM → инструмент → LLM → ответ

## Semantic
### Инструменты
1. **search_papers(query, k, variant)** — поиск по запросу. `variant='reranked'` объединяет BM25 и SPECTER2, `simple` — раздельно.
2. **find_similar(paper_id, k)** — поиск похожих статей через SPECTER2-эмбеддинги.
3. **save_doc(paper_id, filename)** — сохранить данные о документе.

### Данные
Эмбеддинги — specter2 (обучена на научных статьях, title + abstract). Два адаптера под навыки: query-to-article и article-to-article. BM25-корпус синхронизирован с эмбеддингами.

## RAG
### Инструменты
1. **search_chunks(query, top_k)** — поиск релевантных чанков по запросу.
2. **get_chunk_detail(chunk_id)** — полный текст чанка по ID.

### Данные
Эмбеддинги — bge-m3 (был bge-small-en-v1.5). Чанки разбиты по контексту, методы разбиения — эвристические.

## Планы
### Вообще
1) Объединить **RAG** и **Semantic** в одного агента, который сможет искать литературу, качать её, чанкировать, искать нужные фрагменты.
2) Совсем в будущем — дать агенту возможность самому думать над поставленной задачей (а не только отвечать на вопросы).
### Semantic
Сделать реранкер для ответа, а не просто по формуле оценивать релевантность.
### RAG
Увеличить качество изначальной обработки текста и чанкирования.
